# 微信视频号下载

[English](README.en.md) · [中文](README.zh-CN.md)

Android 10+ 视频号下载工具。作者：[nihaomaaa](https://github.com/nihaomaaa)。Kotlin、Jetpack Compose、Miuix。

设置中可选择 [下载网站](https://sph.miuistore.com/) 或腾讯元宝；默认选择网站。打开应用时自动检测网站，打不开则临时使用元宝，网站恢复后仍按用户的原选择使用。手动选择元宝时始终使用元宝。

网站方式无需配置服务器、API Key 或腾讯会话；元宝方式保留原有手机直连方案，需要在应用内的腾讯官方页面登录。两种方式均不要求自行部署服务器。元宝登录或接口限制仍由腾讯控制，自动切换并不保证解析成功。

## 使用

1. 安装签名 APK。
2. 复制视频号分享链接后返回 App，或通过其他应用的分享菜单选择本应用。
3. 等待解析结果，点击“下载到相册”。
4. 如切换到元宝且尚未登录，使用“登录腾讯元宝”入口完成官方网页登录，再重试。可在设置中切换解析方式或重新检测网站。
5. 文件保存到系统媒体库的 `Movies/微信视频号下载`，历史支持播放、分享、重新下载和删除。

仅支持可访问的已发布视频；不支持直播。下载失败会保留可续传状态。网站返回特殊的 `enurl` 格式时会明确提示到原站处理。

# 元宝是怎样帮助下载视频号的？

可以把整个过程想成：**拿着一张取件单，找到包裹，再把它带回家。**

## 1. 分享链接是“取件单”，不是视频文件

你复制的 `https://weixin.qq.com/sph/…` 告诉微信“这是哪条视频”。它通常没有直接包含可以保存的 MP4。

就像知道包裹编号，不代表已经拿到包裹。下载器首先需要找到真正的视频地址。

## 2. 元宝在这里扮演“能查取件单的服务台”

元宝本身有理解视频号链接的功能。这个 App 的元宝方案利用腾讯网页实际使用的解析入口，提交你粘贴的链接，尝试取得腾讯返回的播放链接，再向视频号取得视频文件地址。

**视频由腾讯提供。大模型没有生成或猜出视频，也不是让元宝写一段下载代码。

## 3. 为什么要登录？

登录就像领取一张临时通行证，腾讯用它确认“是谁在请求”。你只需要在 App 展示的腾讯官方页面完成正常登录，不用购买服务器、填写 API Key 或手动复制 Cookie。Cookie 可以理解为网页保管的这张通行证。

App 会向腾讯检查通行证是否被认可。确认后自动保存并返回，提示“已成功”。设置里的登录卡片会显示结果。

**登录成功和视频能下载是两回事。** 有待下载链接时，App 还会检查这条视频。没有链接时只确认登录，不会拿别人的示例视频额外测试。某条视频删除、受限或解析失败，不代表账号一定退出了。

## 4. 谁把视频保存到相册？

取得地址后，App 从腾讯的视频服务器一块一块下载文件，检查它确实是视频，再登记到 Android 的系统媒体库，相册就可以找到它。元宝不是替你把视频存进手机的那个程序。

这条路线是：

**分享链接 → 腾讯确认登录 → 元宝帮助取得播放链接 → 视频号返回视频地址 → App 下载并保存到相册。**

部分公开视频可能直接取得地址，不必走完整登录流程。

## 5. 为什么浏览器登录后不能直接带回来？

手机浏览器和 App 内的登录页，像两个各自保管门卡的房间。你在浏览器领了门卡，App 不能直接去拿。

ChatGPT 那类自动返回登录，需要服务方专门发给 App 一张可验证的“交接凭证”。截至本版研究，没有找到腾讯元宝提供给本应用的这种公开接入方式。仅仅跳回 App 不等于带回了登录资格。

所以，外部浏览器入口可以备用打开官网，**不能自动把浏览器中的元宝登录搬回 App**；目前自动检测、保存和返回适用于应用内的官方登录页。

## 6. 会有额度吗？能永久使用吗？

本 App 没有设置每天只能解析几次。但腾讯可能限制请求、要求验证或更改接口；下载网站也有自己的规则。两种服务都不是开发者能承诺永久可用的。

设置里的“下载网站”和“腾讯元宝”是两条独立路线：网站能用时可以不登录元宝；网站不可用时自动回退到元宝，需要元宝接受你的登录。

只用一句话记住：**元宝方案借助腾讯现有的视频访问能力找地址，App 负责下载；登录是通行证，不是购买大模型额度。**
