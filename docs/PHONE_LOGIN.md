# 手机内登录与下载（1.3）

不用购买解析服务，不用购买或配置服务器，不需要填密钥，也不用找 Cookie。

## 第一次用

1. 在首页粘贴视频号分享链接。
2. 如果看到视频封面，但提示需要登录，点击“登录后获取下载地址”。也可以从设置打开“腾讯网页登录”。
3. 页面上方会显示腾讯网址 yuanbao.tencent.com。下方是腾讯自己的页面；使用它提供的手机号验证码等方式正常登录。不要把手机号、验证码或登录信息发给开发者。
4. 登录完成后，点击最下方“完成登录，返回”。App 会重新处理刚才的链接。
5. 取得下载地址后，点击“下载到相册”。仅有标题和封面时，不会把它假装成可下载的视频。

腾讯页面首次打开可能载入较慢。已在 Android 16 模拟器的系统网页组件 133 上看到真实手机号、验证码和 QQ 登录表单；没有提交手机号、发送验证码或代替用户登录。页面语言由腾讯和设备语言决定，英文 Log In 就是“登录”，Mobile Number 是“手机号”，Verification Code 是“验证码”。

## 如果遇到问题

- **提示网页组件过旧：** 在手机应用商店更新 Android System WebView，或更新系统。本应用登录页要求其主版本至少 100；这不是要求升级到 Android 100。Android 10 模拟器自带的 74 已做明确拦截提示，避免空白页。更高版本也仍需腾讯网页兼容。
- **暂时空白：** 等页面加载，持续空白可点“重新加载”；检查网络。
- **保存会话后仍提示登录：** 点返回不等于腾讯已经登录成功。再次进入页面，确认实际登录完成后重试。
- **腾讯拒绝或暂时限流：** 按提示重新登录或稍后再试；不属于本 App 的付费次数。
- **只有信息没有视频：** 可能会话或接口不可用，也可能是直播、图集或访问受限内容；不能把封面当视频下载。

## 隐私与验证状态

App 只管理自己内部网页的登录记录，不读取微信或外部浏览器的登录数据。会话由 Android 的应用内网页组件保管，应用备份关闭；只向腾讯元宝发送对应会话，不向视频 CDN 或其他服务发送 Cookie。

设置中的“清除本机网页登录”只清除本应用网页记录，不退出手机微信，也不删除下载历史。

当前交付尚未取得本人有效账号，因此没有完成“登录成功 → 解析 → 完整下载”的真实验收。完整原视频下载并能从相册播放，才算这一链路成功；网页登录表单、标题封面和模拟测试都不能替代它。
