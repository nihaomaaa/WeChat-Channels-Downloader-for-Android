# 1.5 双解析方式与网站回退

默认偏好为用户指定的 https://sph.miuistore.com/；设置中也可直接选择腾讯元宝。网站是独立第三方，不是 App 自建服务，也没有永久免费保证。

## 选择与自动切换

- Preferences 保存 WEBSITE/YUANBAO；元宝旧解析器、官方登录页和会话管理均保留。安装升级不会删除元宝会话。
- MainActivity.onStart 请求检查网站；首次解析也等待同一个检查。ResolverRouter 的 Mutex 合并并发请求，60 秒内复用结果，避免旋转或登录返回重复请求。设置“重新检测网站”可立即检查。
- WebsiteProbe 以 HTTPS GET 检查首页；5 秒总超时，无缓存、无 Cookie、不跟随重定向，最多读取 32 KiB，验证 HTTP 2xx、HTML 与站点标识。不是 ICMP ping，也不携带分享链接。
- 用户选择网站且检查失败：本次临时使用元宝。保留用户原偏好，后续检查恢复后重新使用网站。
- 用户手动选择元宝：不因网站恢复而更改选择；启动检查仍执行，但不会向网站发送分享链接。
- 网站解析失败会再检查首页，只有站点不可用才回退。单个视频失效、额度/业务拒绝但首页仍可访问时，保留真实错误，用户可手动换方式；首页可访问不代表每条视频都能解析。
- 选择变更取消旧的首页解析并清空旧预览；已有下载继续使用已获取的地址。历史重试需要刷新过期地址时，使用当前策略。
- 首页及设置显示实际路线/回退状态，视频结果也标记来源。自动回退到元宝后如缺少会话，提供官方网页登录入口；不会伪造免登录成功。

健康检查不保存公网状态到磁盘；冷启动重新检查。网络、TLS、HTTP 或页面格式异常都可能导致回退。新的站点页面结构应先更新 WebsiteProbe 的识别条件，再检查 MiuiSiteClient。

## 实际协议来源

研究站点公开 sph.js 与 enc.js。正常页面把 SPH 短码加上 `##1`，调用它提供的 `AlgoSign({appId:'sph'})`，随后 GET `/sph/public/quick`。App 通过临时的应用内网页执行当前网站脚本，不逆向或打包签名算法、不伪造付费状态、不修改次数信息。

成功响应包含 `url`、`media.title`、`_data`。2026-09-21 的安卓探测曾得到真实成功响应，文件大小 6,808,251 字节，`_data` 解码后为 131,072 字节。该记录不是 1.5 新版完整下载证明。

`_data` 是文件开头的 XOR 掩码。它写入应用私有文件，以 SHA-256 标识保存到历史；下载器按绝对偏移逐块处理，不把大视频装入内存，不在完整下载之后重复解密。续传测试覆盖 71,000 字节处的中途恢复。

## 检查与维护顺序

1. 原站手动输入同一分享链接是否有效，是否出现登录、验证、限流或付费。
2. 网站公开脚本的 AlgoSign、请求路径、短码规则是否变化。
3. MiuiSiteClient 的同源 HTTPS 资源限制是否与正常页面新依赖冲突。
4. 返回 error/message、url、media、_data 的结构和文件头格式。
5. 最终 MP4 能否由系统解码并从 MediaStore 播放。

业务拒绝会如实显示，不能把所有错误改写为额度不足。只接受腾讯 HTTPS 媒体域名，遇到 enurl 特殊变体明确拒绝。不会轮询多个公共解析站。网站不可用时仅回退到用户可见的元宝方式，使用本机保存的腾讯会话。

## 元宝方式

LocalTencentResolver 沿用原手机内腾讯协议；TencentLoginActivity 展示腾讯官方页面，TencentSession 管理本应用中的会话。Cookie 不会发送给下载网站或视频 CDN，也不写日志。没有会话时可能只返回标题、作者等匿名信息；这不等于取得下载地址。元宝方式没有完成本轮已登录账号的真实完整下载验收，不能承诺所有账号/视频永远可用。

## 外部边界

没有反向代理、自建服务器或作者代付账号。站点仍然可能记录请求、限制频率或改变免费政策。只有真实解析、完整流式下载、系统解码、相册可见全部成功，才算端到端验收。
