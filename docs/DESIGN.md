# Apple 风格设计约定

依据用户指定的 finesse-ui 0.22.0，采用手机应用布局与 Apple app 模式。它是原生 Android Compose 工程，不是 H5 网页；技能中的 CSS/浏览器检查按 Android 的 Insets、语义节点、触摸区域和系统动画设置映射。

## 保留与调整

- 保留三页信息架构和原有液态玻璃底栏，包括选中镜片、拖动与文字标签。
- 浅色背景 #F2F2F7、白色内容面，深色背景 #000000、内容面 #1C1C1E。
- 蓝色主操作 #0066CC，深色 #70B8FF；正文使用平台系统字体。
- 大标题 32–34 sp，正文 14–18 sp，中文多行保留足够行距。
- 内容面 24 dp 圆角，内边距 20 dp；按钮使用胶囊外形、按压反馈和克制的阴影。
- 首页只围绕链接与视频结果；设置按外观、解析与保存、应用信息分组。
- 不生成装饰图片，只展示解析得到的真实视频封面。

## Progressive Blur

ProgressiveEdgeBlur.kt 对真实内容背景采样，叠加 3 / 9 / 18 dp 模糊半径，每层使用不同位置的渐变透明遮罩。强度随接近屏幕边缘逐渐增加，中心内容不模糊。顶部覆盖状态栏与相邻边缘，底部覆盖悬浮导航后的区域。

这是分层近似的渐进模糊，不是 Apple 私有实现。Android 12+ 使用 RenderEffect；Android 10/11 降级为高不透明度渐变底色。导航原有镜片在 Android 13+ 使用 RuntimeShader。

## 验收边界

finesse 的静态 detector 已运行，但其主要面向 HTML/CSS，不能证明 Compose 视觉效果正确。本轮设备启动失败，因此 320/375/414 宽度、长文字、深浅色、滚动模糊、拖动中断和 GPU 性能仍需真机/可运行模拟器复核。不得把旧截图放进 README 冒充新版。

可用性检查：系统状态栏不伪造时钟；三页有底部留白；主操作至少 48/56 dp；导航可点击也可拖动；不引入定时自动装饰动画。后续维护需补充更大字体、减少透明效果和对比度辅助设置的实测。
